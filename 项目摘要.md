## Lumina 智能照明解决方案网站 - 最终交付文档

### 1. 网站访问说明

1.1 CloudFront 默认域名访问

您的网站已部署并通过 Amazon CloudFront 进行全球内容分发。您可以通过 CloudFront 分配给您的默认域名访问网站。该域名通常格式如下：

`dXXXXXXXXXXXXX.cloudfront.net`

*   注意：请将 `dXXXXXXXXXXXXX.cloudfront.net` 替换为您 CloudFront 分配的实际域名。您可以在 AWS CloudFront 控制台中找到此域名。

1.2 生产（自定义）域名访问 (需要您完成配置)

为了使用您自己的生产域名（例如 `www.yourdomain.com` 或 `yourdomain.com`）访问网站，您需要按照以下步骤配置 AWS 服务：

1.  获取 SSL/TLS 证书:
    *   在 AWS Certificate Manager (ACM) 中为您的生产域名申请或导入一个 SSL/TLS 证书。强烈建议使用 ACM 申请证书，且必须在 `us-east-1` (弗吉尼亚北部) 区域操作，因为 CloudFront 需要此区域的证书。
2.  配置 CloudFront 分配:
    *   在 CloudFront 控制台中，编辑您的分配设置。
    *   在 “Settings” (设置) 下的 “Alternate domain name (CNAME)” (备用域名) 字段中，添加您的生产域名（例如 `www.yourdomain.com`）。
    *   在 “Custom SSL certificate” (自定义 SSL 证书) 字段中，选择您在 ACM 中准备好的证书。
    *   在 “Behaviors” (行为) 选项卡中，编辑默认行为，将 “Viewer Protocol Policy” (查看器协议策略) 设置为 “Redirect HTTP to HTTPS” 或 “HTTPS Only”，以强制使用 HTTPS。
3.  配置 Route 53 DNS:
    *   登录 Route 53 控制台，进入您的域名对应的 “Hosted zone” (托管区域)。
    *   创建一条新的记录。
    *   选择记录类型为 A。
    *   启用 Alias (别名) 选项。
    *   在 “Route traffic to” (路由流量到) 选项中，选择 “Alias to CloudFront distribution” (到 CloudFront 分配的别名)。
    *   在下拉列表中选择您的 CloudFront 分配域名 (`dXXXXXXXXXXXXX.cloudfront.net`)。
    *   如果您的 CloudFront 分配启用了 IPv6，您还需要重复上述步骤，创建一条记录类型为 AAAA 的别名记录，同样指向您的 CloudFront 分配。
    *   保存记录。DNS 更改通常需要几分钟到几小时生效。

*   参考文档:
    *   [使用您的域名将流量路由到 Amazon CloudFront 分配](https://docs.aws.amazon.com/Route53/latest/DeveloperGuide/routing-to-cloudfront-distribution.html)
    *   [配置备用域名和 HTTPS - Amazon CloudFront](https://docs.aws.amazon.com/AmazonCloudFront/latest/DeveloperGuide/cnames-and-https-procedures.html)

配置完成后，您就可以通过您的生产域名访问网站了。
