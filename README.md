# Lumina - Smart Home Lighting Control System

A modern, responsive web application for controlling smart home lighting systems. Built with HTML, CSS (Tailwind), and JavaScript.

## Features

- 🌓 Intuitive lighting control interface
- 📱 Responsive design for all devices
- 🌍 Multi-language support (English & Chinese)
- 🎨 Smart scene creation and management
- ⏰ Scheduling and automation
- 📊 Real-time energy monitoring
- 🔐 Secure connection and control
